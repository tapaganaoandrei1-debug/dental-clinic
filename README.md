# Dental Clinic

This repository contains the Dental Clinic appointment and queue system in
[`dental-clinic/`](./dental-clinic/). See its
[README](./dental-clinic/README.md) for XAMPP setup and application details.

## Collaborating

1. Clone the repository and open the `dental-clinic` folder in VS Code:

   ```powershell
   git clone https://github.com/tapaganaoandrei1-debug/dental-clinic.git
   cd dental-clinic/dental-clinic
   ```

2. Create a branch for your change:

   ```powershell
   git switch -c feature/short-description
   ```

3. Make and test your changes, then commit and push the branch:

   ```powershell
   git add .
   git commit -m "Describe the change"
   git push -u origin feature/short-description
   ```

4. Open a pull request on GitHub so the team can review the change before it
   is merged into `main`.

Keep real patient information, database backups, passwords, and other secrets
out of this repository. Each developer should use their own local database and
configuration.
